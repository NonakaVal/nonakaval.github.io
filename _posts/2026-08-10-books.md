## The highest-rated Amazon data science books

Hi, my name is Valdenir Nonaka. I am a data scientist currently learning Python, SQL, and the mathematics and statistics needed to understand what I am coding.

## The project

I found this [Amazon books dataset on Kaggle](https://www.kaggle.com/datasets/patrickgomes/pybooks-amazon?select=Pybooks.csv) and decided to create a list of books with the highest number of votes and the best average ratings. The idea was to produce a useful starting point for anyone curating a data science reading list.

- Particularly valuable for readers who enjoy discovering and organizing books.
- The complete project is available in my [GitHub repository](https://github.com/valNonaka/datascience_books).
- More reading material is available in my collection of [PDF resources](https://github.com/valNonaka/resources).

## Data cleaning

What initially looked like a straightforward task required more work than expected. The dataset contained **122 null values** in the `author` column, so those values had to be completed.

- I used the [Google Books API](https://developers.google.com/books) in a function to complete almost every missing author.
- Five values remained missing, so I used Selenium to collect the author names directly from Amazon.

The null values in `avg_reviews` were all associated with books that had zero votes. Therefore, they could safely be filled with `0`.

The complete cleaning process is available in the [`data_cleaning.ipynb` notebook](https://github.com/valNonaka/datascience_books/blob/main/data_cleaning.ipynb).

## Categorizing and ranking the books

To divide the dataset into categories, I used the [TF-IDF method](https://scikit-learn.org/stable/modules/generated/sklearn.feature_extraction.text.TfidfVectorizer.html) on the book titles with `scikit-learn`.

The six categories were:

- Statistics
- Python
- Data Analysis
- Machine Learning
- Data Science
- Deep Learning

For each category, I generated a CSV file with the top 20 books, sorted by the number of reviews (`n_reviews`) and average rating (`avg_reviews`).

The complete ranking code is available in the [`main_top_books.ipynb` notebook](https://github.com/valNonaka/datascience_books/blob/main/main_top_books.ipynb).
